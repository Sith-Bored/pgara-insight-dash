# PGARA Experimental Results

## Overview
This directory documents the experimental results generated by the PGARA implementation.

## Benchmark Results
The benchmark results are stored in the repository root:

`verified-results.json`

The file contains results from eight deterministic synthetic benchmark cases.

## Algorithms Evaluated
- Static Greedy
- Profile-Weighted Greedy
- Potential Game

## Metrics Reported
- Register assignments
- Spilled live ranges
- Estimated spill cost
- Static spill operations
- Iteration count
- Algorithm stopping reason

## Reproducing Results
Refer to the main README for installation and execution instructions.

Run the benchmark generator from the backend directory:

`python scripts/generate_verified_results.py`

## Notes
The reported spill costs are estimates from the project's cost model. They are not hardware runtime or memory-traffic measurements.
